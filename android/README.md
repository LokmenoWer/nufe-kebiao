# nufe课表 · 安卓 App 与桌面小组件

基于 Jetpack Compose 与 Jetpack Glance 开发的安卓客户端，采用**本机优先（Local-First）**架构：在 App 内通过受限 WebView 直接登录学校统一身份认证并从教务系统导入课表，由本机完成整学期排课解析、周次推算、课程配色与调课比对，并通过 Android Keystore（AES-256-GCM）加密存储于本机。日课表、全学期周视图、桌面小组件与本机课前提醒均直接读取本机缓存，跨天、跨周无需联网即可自动切换；同时提供可选的“互助与同步”能力（服务器托管双层兜底、Wi-Fi 下端到端 TLS 盲中继协助刷新、以及作为 iOS 小组件与日历订阅的数据源）。

## 功能特性

- **两种桌面小组件**（支持自由拉伸尺寸、按当前大小动态排版、跟随系统深浅色主题）：
  - **今天**：小尺寸（2×2）与 iOS 小号小组件一致，聚焦展示当前最关键的一节课——“上课中 / 下一节”（调课课程附注“· 调课”）、大号起止时间、课程名、教室及实时倒计时（上课中显示“还剩 mm:ss”，下一节显示“距上课 h:mm:ss”，由系统 `Chronometer` 组件每秒自动走时），底部提示“之后还有 N 节”或停课信息。更大尺寸按可用高度列出当天剩余课程：课程名（调课标注“调”）、“起止时间 · 教室”（空间充足时附带教师姓名，调课标橙色），右侧展示“上课中 / 下一节”与实时倒计时；超出高度的课程折叠为“还有 N 节 · 到 HH:mm”（停课信息优先展示）。当天无待上课程（今日课程已全部结束、全天无课、周末或假期）时，顶部以 `⭐️` 展示三态空态说明与明日提示，下方通过细分隔线隔开并直接列出明天课表或重点展示下次上课预告（2×2 小尺寸下将第一节课时间并入“下次上课”行并允许换行，避免截断）；标题栏同步显示今天/明天剩余课程门数；开学前显示“距开学还有 N 天”，结课后显示“本学期课程已结束”。
  - **本周**：与 iOS Scriptable 的 `week` 模式一致，采用标准教务课表网格布局——纵轴按节次等高排列，课程卡片从起始节延伸至结束节，午休与傍晚等间隔时段压缩为细分割线；左侧时间轴在每节课顶边旁标注**准确的开始时间**（空间允许时附注“第几节”），底边旁标注**下课时间**（如“–09:45”；若部分课程缺少节次信息且无法补齐，则自动切换为按真实时间轴排版）。空间充足时卡片内也显示“10:00–12:15”（窄列自动缩小字号至最低 80% 或折为两行）；**当时间与教室无法同时放下时优先显示教室**，起止时间可直接参考左侧时间轴。若同节次内个别课程起止时间相差数分钟、无法与时间轴完全对齐，卡片内会独立保留其起止时间。**自适应内容排版**——先确保每张卡片的核心信息完整显示，再将剩余高度按节次数分配。卡片内容按优先级依次展示：完整课程名 → 教室（整行放不下时将教学楼名拆至下一行，空间极窄时仅保留房间号如“Z4-118”）→ 起止时间 → 调课原安排 → 教师姓名；高度极矮时仅保留一行课程名。文字排版通过与小组件一致的系统字体（`StaticLayout`）精确测量每段文本高度，并自动适配系统字体大小。已结束课程自动变暗，正在上课的课程实色高亮，停课标“停”，调课标“调”，时间冲突课程标“+1”。当本周剩余课程全部上完后，按当前时刻自动切换展示下周课表。
  - **自由拉伸重排**：采用 `SizeMode.Exact` 按实时宽高动态计算版面。拉高时优先补全教学楼名与教师姓名，再放大字号（最高 1.2 倍）；拉矮时按“教师 → 教学楼名 → 时间 → 课程名行数”逐级精简，仅在必要时缩小字号（最低 0.8 倍）；拉窄至单列不足 40dp 时优先隐藏无课日，仍放不下时仅展示从今天起的若干天，标题栏日期范围随之同步。
  - **小组件选择器预览**：两个小组件均配置了 `android:previewImage`（静态 PNG）与 `android:previewLayout`（Android 12+ 矢量示意布局），并在 Android 15+ 上通过 Glance `providePreview()` 提供动态预览。
  - **固定清晰配色**：小组件背景不随壁纸动态染色（浅色模式使用柔和暖白，深色模式使用中性深灰），避免在 HyperOS / MIUI 等系统上因壁纸取色导致文字对比度下降；平板设备上“今天”小组件仅在 1×1 尺寸下使用单节紧凑模式，1×2 与 2×2 均展示课程列表。
- **点击动作与标题栏状态**：点击“今天”或“本周”桌面小组件会直接打开 App 内的日课表或周课表视图，无网络也能查看本机已保存的整学期课程。小组件标题栏支持展示在 App 重新登录、N 天未更新、离线、有调课及当前周次；点击右上角刷新按钮可立即触发本机后台同步。
- **调课与登录失效提醒**：
  - **调课通知与详情卡**：本机刷新对比出今天及以后的排课变动（时间/教室调整、停课、新增，以及同名课程停课与新增合并为换日）时，发送“课表有变化”（如“第X周调整了课程，点击查看详细信息”）系统通知；App 首页同步展示「调课提示」详情卡，逐条平铺列出周次、课程名与可读变更明细，支持点击“前往查看”直接跳至对应周次，点击右上角“✕”关闭后持久记住已读状态。
  - **登录失效提醒**：当本机学校登录态过期（且无近 24 小时内正常的服务器托管副本兜底）时，除小组件标题栏提示外，App 首页会展示醒目提示卡片与“在 App 内登录”入口，“我的”页面同步标注“需登录”，并发送一条系统通知（点击直达学校登录页，每次失效仅提醒一次，恢复正常后自动撤回）。登录失效期间已保存的课表仍可离线查看。
- **上课提醒**：根据未来 7 天课表在本机设置精确闹钟通知（含课程名、起止时间、教室，调课课程注明原安排，右侧带彩色应用大图标），默认提前 **20 分钟**，支持自由调整提前分钟数（1–60 分钟）或关闭提醒；每次同步新课表后自动重排，设备重启、覆盖安装或修改时区后自动恢复。
- **刷新与重绘调度**：WorkManager 每 30 分钟联网直连教务系统定期同步兜底，并在每节课课前 25 分钟及上下课时刻调度同步；同时在上下课时刻与每日零点通过本机精确闹钟触发纯重绘（不发起网络请求，确保系统倒计时与课程状态准时切换；针对可能延后普通精确闹钟的定制 ROM，“我的”页额外提供“小组件准时切换”开关，开启后改用 `AlarmClock` 调度，状态栏可能显示闹钟图标）。无网络或学校暂时不可达时自动回退至本机加密缓存并标注“离线”。

## App 界面、互助同步与实时提醒

- **首次打开、学校登录与本机加密存储**：
  - **权限引导与首启介绍**：首次启动弹出权限引导弹窗，可逐项开启通知、准时提醒、系统实时提醒、自启动（ColorOS 等机型提供直达入口）及后台运行权限；首次进入欢迎页需阅读并同意《免责声明》后点击“前往学校官网导入课表”；首次安装并成功导入课表后，展示一次性的「欢迎使用 nufe课表」特性介绍弹窗（升级老用户不打扰）。
  - **受限 WebView 登录导入**：`SchoolLoginActivity` 严格锁定 `authserver.nufe.edu.cn` 与 `jwxt.nufe.edu.cn` 的 HTTPS 443 端口（拦截一切非学校域名跳转与子资源请求、启用 `FLAG_SECURE` 防截屏），自动修复学校移动登录模板将多因子认证（MFA）容器裁剪为白屏的问题；导入完成后立即清空 WebView 会话 Cookie，但保留 `WebStorage` 中的设备指纹，避免学校每次登录都触发二次认证。
  - **本机解析与加密缓存**：本机 `TimetableParser` 直接解析教务课表页、`print-data` 与学期详情，推算全学期周次、课程配色与最近 7 天调课记录。整学期课表与姓名、学号通过 Android Keystore 中的 AES-256-GCM 密钥加密存储于 `files/timetable.enc`，学校登录会话加密存储于 `noBackupFilesDir/school-session.enc`，**App 绝不保存密码**。后台刷新由 `LocalFetch` 直连教务系统，教务会话过期时自动用 `CASTGC` 静默换票续期一次，并通过 `touchSso` 保活探针检测 `CASTGC` 是否失效；同教学期若后台自动刷新返回空课表则自动保留原课表，防止教务未发布或会话半失效误清空。
- **主页（课表首屏）**：
  - **常显状态胶囊**：顶部胶囊实时展示当前状态——上课中显示“正在上课 · 剩 X 分钟”，课前显示“准备上课 · X 分钟后”，今天课后或无课时显示“今日无事”。
  - **日视图与全学期周视图**：课表主卡片支持在单日视图与周视图间平滑切换。单日视图支持展开查看今日已结束课程，无待上课程时展示三态空态文案与明日/下次上课预览；周视图按节次网格排版（统一 0.8 档字号并允许课名自动换行长高以完整显示），**支持左右滑动浏览全学期任意周次**（周标题与切换按钮文字随手势同向滑动，滑至本周、下周以外时显示“回到本周”胶囊按钮一键返回），点击任意课程或停课条目可弹窗查看完整时间、节次、教室、调课原安排与教师详情。
  - **今日节奏与学期进度**：课表卡片下方并排展示「今日节奏」（预告明日时为“明日节奏”）圆环表盘与竖向「学期进度」卡片。节奏环支持在“我的 → 首页显示”中切换 **12 小时制**（如真实钟表般展示当前往前 2 小时至往后 10 小时的课程，避免早晚课程重叠）与 **24 小时制**（0 点在正上方，一圈全天），带指针旋转入场动画，全天无课时整圈呈柔和绿色并显示“休息”，当天课程全部结束后显示“已下课”；学期进度卡按 17 周分段着色动画展示当前周次进度。底部采用课表 / 我的 / 关于胶囊导航栏，页面切换配备统一的弹性上浮入场动画。
- **“我的”页面与设置整合**：集中管理个人信息（展示本机加密保存的姓名、学号及当前服务器连接状态说明）、本地学校登录（展示会话状态标签、重新前往教务系统导入课表、应用设置及一键清除本机数据）、首页显示（12 / 24 小时制切换）、互助与同步、添加课表小组件到桌面（含分品牌手动添加指南与小组件准时切换开关）、上课通知（总开关、1–60 分钟 3D 透视滚轮选择器、灵动显示开关及收起时机/进度条/秒级倒计时自定义与一键预览）、系统权限状态检查及提交反馈。
- **互助与同步（人人为我，我为人人）**：「我的 → 互助与同步」中的三项功能全部可选、默认关闭、随时可关，不影响本机课表独立使用：
  - **服务器托管（人人为我，双层兜底）**：在登录页勾选“同时托管到 nufe课表 服务器”或在“我的”中开启后，App 在 Android Keystore 中生成不可导出的 P-256 签名密钥对，将当前学校会话与设备公钥提交至 `/api/app/enroll`。开启后与本机刷新互为兜底：本机直连学校失败时，若服务器托管副本更新则自动拉取 `/mobile/<token>/timetable` 顶上（服务器副本在 24 小时内正常时，本机会话过期也不打扰重登）；当本机刷新成功而服务器登录态失效时，自动将本机最新学校会话补交至服务器。关闭托管会通知服务器立即删除保存的学校登录状态（未开启 iOS 数据源时同步撤销设备）。
  - **协助刷新（我为人人，端到端 TLS 盲中继）**：开启后，WorkManager 每 30 分钟在**非计费网络（Wi-Fi）且电量不低**时向服务器轮询协助任务（`/api/assist/claim`），通过 `AssistRelay` 为网页版或托管同学盲转发发往 `jwxt.nufe.edu.cn:443` 的 TLS 密文字节流（`/api/assist/exchange`，按 512 KB 分批交换避免单包超限）。服务器与学校教务系统之间直接完成端到端 TLS 加密，本机仅搬运密文，无法查看或修改任何人的 Cookie 与课表，且严格锁定 `jwxt.nufe.edu.cn:443` 防止被用作任意代理。单轮最多协助 3 个任务、最长运行 2 分钟，每日流量封顶 30 MB，界面实时展示累计帮助同学刷新的次数。
  - **iOS 小组件与日历数据源**：适合同时拥有 iPhone / iPad 的用户。开启时用本机学校会话向服务器验明身份并绑定设备（若未开启服务器托管，服务器不保存学校登录状态），此后本机每次刷到新课表即通过设备私钥签名推送至 `/mobile/<token>/push`，由服务器转发给 iOS Scriptable 小组件与 `.ics` 日历订阅；在卡片内可直接一键复制或分享“小组件脚本链接”与“日历订阅链接”到 iPhone。
- **提醒生命周期与跨系统灵动显示**：课前按设定的提前分钟数发出标准通知；开启**灵动显示**后，App 在实现 Android 16+（API 36+）原生 `Live Updates` 的系统（如 ColorOS 16 流体云及其他支持 `Promoted Ongoing` 的 Android 16 系统）上直接启用 `Promoted Ongoing` + `ProgressStyle` 系统实时通知（卡片固定按「第一层：上课时间与教室 → 第二层：课程名 → 第三层：xx后上课 / xx后下课倒计时」三层结构展示，不显示冗余左侧应用大图标），同时在 `Notification.extras` 中附带主流定制系统的实验性扩展字段（如小米 `miui.focus.param`、魅族/华为/荣耀 `notification.live.*`、vivo `notification.superx.*` 等；在未开放第三方白名单的机型上会自动回退为常驻倒计时通知，且不影响正常课前响铃提醒）。用户可在「我的 → 上课通知」中自由定制**自动收起时机**（开课 5 分钟后 / 上课时立即收起 / 持续展示至下课）、**卡片进度条**与**秒级倒计时**开关，并支持点击「立即预览」一键查看效果（预览不会注册系统闹钟）。展示期间会启动独立进程前台守护服务（`LiveUpdateGuardService`）按分钟（开启秒级倒计时时按整秒）刷新倒计时与进度，防止清理后台时卡片被系统收起，支持被系统回收后按持久化配置自动恢复。关闭“上课通知”会立即取消所有待触发的闹钟与实时通知。
- **触感反馈**：滚动时间拨轮、切换周次与视图、切换底部导航标签及拨动开关时均提供系统原生触感反馈。
- **提交反馈与诊断日志**：“我的 → 提交反馈”支持跳转 GitHub Issue、发邮件联系开发者，或一键导出脱敏诊断日志（包含应用版本、机型、权限状态、本地课表与缓存状态及最近运行日志；敏感链接与邮箱地址自动脱敏）。
- **匿名统计与应用内更新**：
  - **匿名统计心跳**：`HeartbeatWorker` 每天最多向项目服务器发送一次匿名心跳（`/api/app/heartbeat`），仅含本机随机生成的 `install_id`（服务端仅存哈希）、应用版本、系统 SDK 版本、是否已导入课表及是否开启协助刷新，不含学号、姓名或课表。
  - **应用内检查更新**：启动 App 时每天最多自动检查一次 GitHub Releases，也可在“关于 → 检查更新”中手动触发；当无法直连 GitHub 时自动回退至项目服务器镜像 `/android/releases.json` 与 `/android/apk/<版本>.apk`。发现新版本时主页展示更新卡片（可选择“先不更新”跳过当前版本），点击“立即更新”后由 App 下载安装包并在本地严格校验包名、版本号与签名证书，通过后拉起系统安装界面；首次更新需授予“安装未知应用”权限，若下载或校验失败可重试或改用浏览器下载。正式版仅检查正式版更新，预发布版同时检查正式版与预发布版。
- **权限状态管理**：首次启动引导弹窗后不会重复打扰，后续可随时在“我的 → 权限”中查看并跳转开启通知、准时提醒、系统实时提醒、自启动与后台运行权限；未允许后台不受限运行时，提醒卡片会给出提示与快捷设置入口。ColorOS 的电池白名单不等于后台放行，还需要在“耗电管理 / 自启动”里单独允许，App 会优先提供厂商后台与自启动设置入口。
- **跨平台实时通知说明**：App 采用零专有 SDK 的标准 API + `Notification.extras` 实验性扩展双层架构：Android 16+ 系统通过原生 `POST_PROMOTED_NOTIFICATIONS` 展示系统级灵动胶囊与实时卡片；在 Android 15 及以下定制 ROM 上尝试附带厂商扩展参数，若系统未识别或对第三方包名启用白名单校验，则自动作为常驻进度/倒计时通知展示，且同次普通课前提醒照常响铃弹出。
- **图标致谢**：底部导航与方向图标采用 [IconPark](https://github.com/bytedance/IconPark)（Apache-2.0 许可证）单色矢量图标。

## 构建指南

环境要求：JDK 17+ 与 Android SDK（`compileSdk 37`）。可使用 Android Studio 直接打开 `android/` 目录，或在命令行构建并运行单元测试：

```bash
cd android && ./gradlew :app:assembleDebug :app:testDebugUnitTest
```

构建产物位于 `app/build/outputs/apk/debug/app-debug.apk`（Debug 包应用 ID 为 `wiki.nufe.kebiao.debug`，可与正式版并存安装）。构建正式签名发布包时，请在 `android/keystore.properties`（已加入 `.gitignore`）中配置 `storeFile` / `storePassword` / `keyAlias` / `keyPassword`，然后执行 `./gradlew :app:assembleRelease`。如需指定项目服务器地址（默认 `https://kebiao.nufe.wiki`），可附加 `-PkebiaoSite=https://beta.kebiao.nufe.wiki`。

## 调试方法

- **联调本地服务与协助/托管任务（仅 Debug 包）**：Debug 包的 `network_security_config` 已对 `10.0.2.2` 与 `localhost` 放行明文 HTTP，可通过 `run-as wiki.nufe.kebiao.debug` 在 `shared_prefs/community.xml` 中配置 `dev_site` 指向本地开发服，并通过启动参数立即触发单次协助刷新或服务器托管同步：

  ```bash
  adb shell am start -n wiki.nufe.kebiao.debug/wiki.nufe.kebiao.ui.MainActivity --ez assist_now true
  adb shell am start -n wiki.nufe.kebiao.debug/wiki.nufe.kebiao.ui.MainActivity --ez host_now true
  ```

- **桌面小组件多尺寸预览（仅 Debug 包）**：无需反复往系统桌面拖拽，即可在一页内同时预览 2×2 至 4×5 以及窄列 2×3、3×3 等各种尺寸的排版效果；支持通过 `--es at 09:30` 指定模拟时刻以检查上课中、课前倒计时、课后切换明天等状态，或通过 `--es only 本周` 仅渲染指定类型的小组件：

  ```bash
  adb shell appwidget grantbind --package wiki.nufe.kebiao.debug
  adb shell am start -S -n wiki.nufe.kebiao.debug/wiki.nufe.kebiao.preview.WidgetPreviewActivity --es at 09:30
  ```

- **实时提醒测试（仅 Debug 包）**：进入“关于 → 开发者选项 → 实时提醒测试”可打开 Live Updates 调试页，直接验证流体云、真实下一节课预览、普通通知回退及开课状态切换；点击“15 秒后闹钟测试”会通过真实的 `AlarmManager` 调度提醒，点击后按 Home 键退至后台即可验证准时唤醒。
- **Glance 布局约束注意**：Glance 的 `Row` / `Column` / `Box` 容器单个节点最多支持 10 个直接子元素，超出将导致小组件渲染报错；因此列间距统一采用 `padding` 而非独立 `Spacer`，单日课程每节仅占一个子元素。

## 已知限制

- 国产定制系统（MIUI / HyperOS、ColorOS、OriginOS、HarmonyOS 等）默认会严格限制后台应用，请在系统电池或应用管理设置中允许本 App“自启动”与“后台不受限运行”，否则小组件刷新与课前提醒可能被系统推迟。
- 在会延后普通精确闹钟的系统上，课前提醒与“小组件准时切换”采用 `setAlarmClock` 调度，以避免被系统归入最长 1 小时的弹性合并窗口；代价是系统状态栏可能显示闹钟图标，锁屏界面也可能显示下一次闹钟时间。
- 若未授予“闹钟和提醒”（精确闹钟）权限（Android 12+ 需用户在系统设置中手动开启），课前提醒将降级为非精确闹钟，触发时间可能延后数分钟。
- 4×2 尺寸的“本周”小组件纵向空间较矮，仅能展示课程名称；4×3 及以上尺寸可完整显示教室并在左侧时间轴标注起止时间，4×4 及以上尺寸还可在卡片内同时展示起止时间、教学楼名与教师姓名。
