# nufe课表 · 安卓桌面小组件

用 Jetpack Glance 写的安卓 App，给安卓用户提供和 iOS Scriptable 小组件同样的桌面体验。数据直接读服务器的 `GET /mobile/<token>.json`（与 Scriptable 脚本共用只读 token，旧的 `/widget/<token>.json` 链接继续可用），周次、颜色、调课标记都由服务端算好，App 只负责排版、定时刷新和上课提醒，服务端不需要任何改动。

## 功能

- **两种小组件**，核心体验和 iOS Scriptable 小组件一一对应（都可以自由拉伸，按实际尺寸排版，跟随系统深浅色，Android 12+ 用 Material You 动态取色）：
  - **今天**：2×2 和 iOS 小号一样只显示最要紧的一节——“上课中 / 下一节”（调过的课加“· 调课”）、大字起止时间、课程色课名、教室、倒计时（上课中“还剩 mm:ss”，下一节“距上课 h:mm:ss”，不论多久以后都显示；系统 `Chronometer` 每秒自己走，iOS 那边下一节只写“X 小时后”），底下“之后还有 N 节”或停课。更大的尺寸按高度列出剩下的课：课名（调过的加“调”）、“起止 · 教室”（拉大了再加教师；调过的标橙色），右边“上课中 / 下一节”和倒计时；放不下的合成“还有 N 节”，有停课时停课优先。今天的课全部结束后**自动切换成明天的完整课表**；标题同时显示今天/明天还有 N 门课；明天没课、周末、假期里显示下次上课预告；开学前显示“距开学还有 N 天”，结课后显示“本学期课程已结束”。
  - **本周**：和 Scriptable 的 week 模式一样是学校课表的样子——纵轴按节次，用到的每一节一样高，课从起始节画到结束节，午休、傍晚这种隔开的地方压成一道细缝；左边时间轴在每节课顶边旁写**准确的开始时间**（放得下时在下面注“第几节”），底边旁写**下课时间**“–09:45”（有课没写节次又补不上时改按真实时间）。放得下时卡片上也写“10:00–12:15”（列窄时字号按列宽缩，最多到 80%，再窄就分两行）；**时间和教室放不下两样时优先写教室**，起止时间看时间轴。按节次排时同一节开始 / 下课的课差几分钟、时间轴对不上的那几节，卡片上自己保留时间。**按内容排**——每张卡片先保证写得下，剩下的高度再按节数分。卡片里依次写：课名写全 → 教室（放不下整行时楼名单独一行，再不行只写“Z4-118”）→ 起止时间（时间轴上有时最先省）→ 调课的原安排 → 教师；格子矮得连边距都放不下时只写一行课名。字不靠估：用画小组件的同一套系统字体（`StaticLayout`）量出每段字多高，跟随系统字体大小。已上完的课变灰，正在上的课实色高亮，停课标“停”，调课标“调”，撞课记作“+1”。周末本周没课了自动看下周。调过的课课名和时间标橙色。
  - **随意拉伸**：版面全按当前尺寸算（`SizeMode.Exact`）。拉高了先写全楼名和教师，再把字放大（最多 1.2 倍）；拉矮了逐级少写（教师 → 楼名 → 时间 → 课名缩成两行 / 一行），要紧的内容才缩字（最小 0.8 倍）；拉窄到一列不足 40dp 时先省掉没课的日子，还放不下就只画从今天起的几天，标题里的日期跟着变。
  - **缩略图**：两个组件都配置了 `android:previewImage`（静态 PNG）和 `android:previewLayout`（Android 12+ 的示意布局）作为桌面选择器的兜底；Android 15+ 还会通过 Glance `providePreview()` 发布生成的预览。
- **标题栏提示**：需重新登录、N 天未更新、离线、更新中、有调课、第几周；右上角刷新按钮会请服务器插队向学校拉一次（`?refresh=1`，服务器自己限流）。
- **点击**：打开网站对应那天的日视图 / 那一周的周视图；本周小组件点某一列进那天。
- **上课提醒**：按未来 7 天的课在本机定闹钟发通知（课程、时间、教室，调过的课注明原安排），可选关闭 / 提前 5–30 分钟。每次拿到新课表整批重排，开机、改时区后自动恢复。
- **刷新时机**：WorkManager 每 30 分钟兜底一次；另外在下一个上下课时刻、课前 1 小时（切换成倒计时）、课前 25 分钟（服务器刚在课前半小时确认完课表）、零点后各重画一次；服务器正在向学校拉课表时约 2 分钟后再看。断网时用本机缓存并标“离线”。
- **设置链接**：网站 → 账号与设置 → 安卓 App → “在安卓 App 中打开”（`nufekebiao://setup?url=…&pair=…`），或复制链接后在 App 里粘贴，也可以从别的 App 分享文字过来。

## App 界面与实时提醒

- **首次打开**：先弹出权限引导，逐项开启通知、准时提醒和系统实时提醒；顶部是“nufe课表”，下方直接粘贴网站生成的 `/mobile/<token>.json` 链接，输入框旁“确认”校验成功后进入主页；校验失败会留在当前页并提示，不会保存坏链接。
- **主页**：标题下是“今天”的课表（当天课程结束后自动切到“明天”的完整课表；可展开全天，并显示还有 N 门课要上）、聚合的“添加课表小组件到桌面”（弹窗选择今天 / 本周）和提醒卡片；提醒卡片分开为“上课前提示时间（1–60 分钟，数字滚动、‘提前 / 分钟’固定，带透视效果）”“上课通知开关”“流体云显示开关”。底部是课表 / 我的 / 关于胶囊导航，内容页只做小幅左下 / 右下弹入，不再整页翻页。
- **提醒生命周期**：课前按设定的提前时间发提醒；流体云仅适配 ColorOS 16+，在开课时切成“正在上课”，开课 5 分钟后静默收起，不再发下课提示；普通通知也在开课 5 分钟后自动消失。关闭“上课通知”会取消所有待发的提醒。
- **触感**：滚动时间拨轮、点击底部导航和切换开关时使用系统触感反馈。
- **诊断日志**：“我的 → 帮助开发者优化 App”可导出诊断文件，包含版本、设备、权限、链接状态和最近日志；小组件链接、密码和邮箱会自动打码，再通过系统分享发送给开发者。关于页提供 GitHub 仓库入口。
- **设备绑定**：姓名、学号等个人信息不在课表 JSON 里。网站“安卓 App → 绑定新设备”生成一次性配对链接（`nufekebiao://setup?url=…&pair=…`，10 分钟有效），App 在 Android Keystore 里生成不可导出的 P-256 密钥并登记公钥，之后凭签名读 `/mobile/<token>/profile`，用 Keystore 的 AES-GCM 密钥加密存在 `profile.enc`。没绑定时课表和小组件照常用，“我的”不显示个人信息；设备被撤销或链接换了会自动清掉本机绑定。
- **本地拉课表**：绑定过的设备会替服务器向学校拉课表（`data/LocalFetch.kt`，移植自 Scriptable 脚本）：带设备签名请求课表 JSON 时服务器才下发 `fetch` 任务，App 用手机的网络访问教务（只认 `https://jwxt.nufe.edu.cn`，每一跳都检查），把原始页面交回 `/mobile/<token>/upload` 由服务器解析。任务里的 cookie 不写缓存、不打日志；抓不到时如实上报，服务器兜底。还按服务器给的 `poll_after` 和课前 37 分钟多取一次。单元测试：`./gradlew :app:testDebugUnitTest`。
- **权限**：首次打开时从弹窗直接跳到系统授权页；确认链接后不会反复弹权限窗，仍可在“我的 → 权限”里重新开启。
- **实时提醒**：复用 `/mobile/<token>.json` 的同步缓存，按用户选的提前分钟数在课前发提醒。**流体云只适配 ColorOS 16+**；其他平台（HyperOS、原生 Android 等）不启用流体云，自动回退为普通通知。普通通知和流体云都在开课 5 分钟后消失。
- **超级岛**：小米超级岛是厂商专有通道，需要小米企业开发者、应用上架、App ID、服务/场景审核，当前不接入；标准 Live Updates 不能直接上岛，当前其他平台统一使用普通通知。
- **图标**：底部导航和展开箭头使用 [IconPark](https://github.com/bytedance/IconPark)（Apache-2.0）的单色矢量图标。

## 构建

需要 JDK 17+ 和 Android SDK（compileSdk 37）。用 Android Studio 打开 `android/` 目录即可，或命令行：

```bash
cd android && ./gradlew :app:assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。发布包需要签名：在 `android/keystore.properties`（已在 `.gitignore`）里写 `storeFile` / `storePassword` / `keyAlias` / `keyPassword`，再 `./gradlew :app:assembleRelease`。

## 调试

- 本机演示：`.venv/bin/python scripts/demo_server.py` 起离线演示站（端口 8765），登录后在设置里生成小组件链接；模拟器里先 `adb reverse tcp:8765 tcp:8765`，链接里的 `localhost` 就能直接用（`network_security_config` 只给 localhost / 10.0.2.2 放行明文 HTTP）。
- 小组件预览（只在 debug 包里）：把两种小组件按 2×2 到 4×5、以及拉窄的 2×3、3×3 画在一页上，不用反复往桌面上拖；`--es at 09:30` 把时钟拨到今天这个时刻，看上课中 / 课前倒计时 / 课上完等状态；`--es only 本周` 只画标题以它开头的几种：

  ```bash
  adb shell appwidget grantbind --package wiki.nufe.kebiao
  adb shell am start -S -n wiki.nufe.kebiao/.preview.WidgetPreviewActivity --es at 09:30
  ```

- Glance 的 Row / Column / Box 最多 10 个子元素，超出会整块小组件报错：列间距用内边距而不是 Spacer，一天的课每节只占一个子元素。

## 代码结构

```text
app/src/main/java/wiki/nufe/kebiao/
  data/      Models（解析 JSON）、Repository（链接 / 缓存 / 下载）、Plan（今天 / 明天 / 本周要画什么，移植自 Scriptable 脚本）
  widget/    Glance 小组件：Common（主题色、标题栏、倒计时、课程卡片）、DayWidget（今天，课后自动切明天）、
             WeekWidget（本周按节次）、WeekLayout（本周按内容排版：节次 / 时间纵轴、量字、分几档内容、解分界线）
  sync/      WorkManager 同步与重画时机
  remind/    上课提醒（AlarmManager + 通知）、开机恢复
  ui/        设置页（Compose）
app/src/debug/  小组件预览页
```

## 已知限制

- 国产系统（MIUI / HyperOS、ColorOS、OriginOS、鸿蒙等）默认会限制后台，需要在电池设置里允许 App 自启动、后台运行，否则刷新和提醒可能不准时。
- 没有“闹钟和提醒”权限（Android 12+ 需要用户手动打开）时，提醒退化为非精确闹钟，可能晚几分钟。
- 4×2 的本周小组件太矮，只写得下课名；4×3 起每节课都有教室、起止时间在时间轴上，4×4 以上卡片上也写时间、楼名和教师。
