# nufe课表 · 安卓 App 与桌面小组件

基于 Jetpack Compose 与 Jetpack Glance 开发的安卓客户端，为安卓用户提供与 iOS Scriptable 小组件一致的桌面课表与上课提醒体验。课表数据直接读取服务端的 `GET /mobile/<token>.json`（与 iOS 小组件共用只读凭证，同时兼容旧版 `/widget/<token>.json` 链接），周次推算、课程配色与调课标记均由服务端完成，客户端专注于桌面小组件渲染、定时同步、手机端代抓课表与本机上课提醒。

## 功能特性

- **两种桌面小组件**（支持自由拉伸尺寸、按当前大小动态排版、跟随系统深浅色主题）：
  - **今天**：小尺寸（2×2）与 iOS 小号小组件一致，聚焦展示当前最关键的一节课——“上课中 / 下一节”（调课课程附注“· 调课”）、大号起止时间、课程名、教室及实时倒计时（上课中显示“还剩 mm:ss”，下一节显示“距上课 h:mm:ss”，由系统 `Chronometer` 组件每秒自动走时），底部提示“之后还有 N 节”或停课信息。更大尺寸按可用高度列出当天剩余课程：课程名（调课标注“调”）、“起止时间 · 教室”（空间充足时附带教师姓名，调课标橙色），右侧展示“上课中 / 下一节”与倒计时；超出高度的课程折叠为“还有 N 节”（停课信息优先展示）。当天课程全部结束后**自动切换为明天的完整课表**；标题栏同步显示今天/明天剩余课程门数；明日无课、周末或假期时显示下次上课预告；开学前显示“距开学还有 N 天”，结课后显示“本学期课程已结束”。
  - **本周**：与 iOS Scriptable 的 `week` 模式一致，采用标准教务课表网格布局——纵轴按节次等高排列，课程卡片从起始节延伸至结束节，午休与傍晚等间隔时段压缩为细分割线；左侧时间轴在每节课顶边旁标注**准确的开始时间**（空间允许时附注“第几节”），底边旁标注**下课时间**（如“–09:45”；若部分课程缺少节次信息且无法补齐，则自动切换为按真实时间轴排版）。空间充足时卡片内也显示“10:00–12:15”（窄列自动缩小字号至最低 80% 或折为两行）；**当时间与教室无法同时放下时优先显示教室**，起止时间可直接参考左侧时间轴。若同节次内个别课程起止时间相差数分钟、无法与时间轴完全对齐，卡片内会独立保留其起止时间。**自适应内容排版**——先确保每张卡片的核心信息完整显示，再将剩余高度按节次数分配。卡片内容按优先级依次展示：完整课程名 → 教室（整行放不下时将教学楼名拆至下一行，空间极窄时仅保留房间号如“Z4-118”）→ 起止时间 → 调课原安排 → 教师姓名；高度极矮时仅保留一行课程名。文字排版通过与小组件一致的系统字体（`StaticLayout`）精确测量每段文本高度，并自动适配系统字体大小。已结束课程自动变暗，正在上课的课程实色高亮，停课标“停”，调课标“调”，时间冲突课程标“+1”。到了周末且本周无剩余课程时自动切换展示下周课表。
  - **自由拉伸重排**：采用 `SizeMode.Exact` 按实时宽高动态计算版面。拉高时优先补全教学楼名与教师姓名，再放大字号（最高 1.2 倍）；拉矮时按“教师 → 教学楼名 → 时间 → 课程名行数”逐级精简，仅在必要时缩小字号（最低 0.8 倍）；拉窄至单列不足 40dp 时优先隐藏无课日，仍放不下时仅展示从今天起的若干天，标题栏日期范围随之同步。
  - **小组件选择器预览**：两个小组件均配置了 `android:previewImage`（静态 PNG）与 `android:previewLayout`（Android 12+ 矢量示意布局），并在 Android 15+ 上通过 Glance `providePreview()` 提供动态预览。
  - **固定清晰配色**：小组件背景不随壁纸动态染色（浅色模式使用柔和暖白，深色模式使用中性深灰），避免在 HyperOS / MIUI 等系统上因壁纸取色导致文字对比度下降；平板设备上“今天”小组件仅在 1×1 尺寸下使用单节紧凑模式，1×2 与 2×2 均展示课程列表。
- **登录失效提醒**：当学校登录态过期或需要填写验证码导致后台刷新暂停时，除小组件标题栏提示外，App 主页会展示醒目提示卡片与“去网站登录”入口，“我的”页面同步标注状态，并发送一条系统通知（每次失效仅提醒一次，恢复正常后自动撤回）。偶发的临时刷新错误仅显示“刷新失败”，由服务端自动退避重试。
- **小组件标题栏状态**：支持展示需重新登录、N 天未更新、刷新失败、离线、更新中、有调课及当前周次；点击右上角刷新按钮可请求服务端优先刷新（`?refresh=1`，受服务端统一限流保护）。
- **点击动作配置**：点击桌面小组件默认在浏览器中打开网站对应日期的日视图或对应周次的周视图（在本周小组件中点击某一天所在列可直达当天）；也可在 App 主页“添加课表小组件到桌面”卡片中切换为点击打开 App 主页。
- **上课提醒**：根据未来 7 天课表在本机设置精确闹钟通知（含课程名、起止时间、教室，调课课程注明原安排），支持自由调整提前分钟数（1–60 分钟）或关闭提醒；每次同步新课表后自动重排，设备重启或修改时区后自动恢复。
- **刷新与重绘调度**：WorkManager 每 30 分钟定期同步兜底；在每节课上下课时刻与每日零点通过本机闹钟触发纯重绘（不发起网络请求，确保系统倒计时与课程状态准时切换；针对可能延后普通精确闹钟的定制 ROM，主页额外提供“小组件准时切换”开关，开启后改用 `AlarmClock` 调度，状态栏可能显示闹钟图标）；此外在课前 37 分钟（代抓确认）与课前 25 分钟（拉取服务端课前 30 分钟确认后的结果）自动同步一次，若服务端正在刷新则约 2 分钟后再次拉取。无网络时自动回退至本地缓存并标注“离线”。
- **快速连接课表**：在网站 → 账号与设置 → 安卓 App 中点击“在安卓 App 中打开”（`nufekebiao://setup?url=…&pair=…`），或复制配对链接后在 App 内点击“粘贴剪贴板”，也支持从其他应用直接分享链接文本至本 App。

## App 界面与实时提醒

- **首次打开与权限引导**：首次启动弹出权限引导弹窗，可逐项开启通知、准时提醒、系统实时提醒及后台不受限运行；连接页面支持直接粘贴网站生成的 `/mobile/<token>.json` 配对链接或点击“粘贴剪贴板”一键识别校验，校验通过后进入主页；若链接无效或网络异常则留在当前页并给出明确提示，不会保存无效链接。
- **主页**：顶部展示当前上课/下课状态胶囊，下方依次为课表卡片（支持在“今天 / 明天”与“本周 / 下周”视图间切换；单日视图在当天课程结束后自动切换为“明天”的完整课表，支持展开查看全天课程并提示剩余课程门数；周视图按节次网格排版，点击任意课程可弹窗查看完整时间、节次、教室、调课原安排与教师详情）、“添加课表小组件到桌面”卡片（支持一键添加到桌面、切换点击打开网页或 App）以及提醒设置卡片。提醒卡片包含“上课通知”总开关、“上课前提示时间”（1–60 分钟 3D 滚轮选择器）与“灵动显示”开关；总开关关闭时下方子项自动置灰禁用。底部采用课表 / 我的 / 关于胶囊导航栏。
- **提醒生命周期与流体云**：课前按设定的提前分钟数发出提醒；**流体云（Live Updates）仅在 ColorOS 16+ 上启用**，开课时刻切换为“正在上课”状态，并在开课 5 分钟后静默收起，不发送下课打扰通知；普通系统通知同样在开课 5 分钟后自动清除。关闭“上课通知”会立即取消所有待触发的闹钟与实时通知。
- **触感反馈**：滚动时间拨轮、切换底部导航标签与拨动开关时均提供系统原生触感反馈。
- **提交反馈与诊断日志**：“我的 → 提交反馈”支持跳转 GitHub Issue、发邮件联系开发者，或一键导出脱敏诊断日志（包含应用版本、机型、权限状态、连接状态及最近运行日志；课表链接、密码与邮箱地址均自动脱敏）。
- **账号连接管理**：“我的 → 账号连接”直观展示当前状态（已连接 / 离线 / 需重新登录）；点击底部“断开连接”可清除本机保存的链接、个人资料与课表缓存。网站账号与已登记的设备记录不受影响。
- **硬件密钥设备绑定**：姓名、学号等个人信息不包含在课表 JSON 中。在网站“账号与设置 → 安卓 App → 绑定新设备”生成一次性配对链接（`nufekebiao://setup?url=…&pair=…`，10 分钟内有效），App 会在 Android Keystore 中生成不可导出的 P-256 密钥对并向服务端注册公钥，随后凭私钥签名请求 `/mobile/<token>/profile` 获取个人信息（仅展示姓名、学号与打码邮箱），并使用 Keystore 中的 AES-GCM 密钥加密存储于本机 `profile.enc`。未绑定设备时课表、小组件与提醒功能均可正常使用，仅“我的”页面不展示个人身份信息；若设备在网页端被撤销或更换了链接，本机绑定信息会自动清除。
- **手机端代抓课表**：已绑定的设备在请求课表 JSON 时携带设备签名，服务端验证通过后会在需要刷新时下发 `fetch` 代抓任务（`data/LocalFetch.kt`）；App 使用手机网络直接访问教务系统（严格锁定 `https://jwxt.nufe.edu.cn` 域名并校验每一次重定向），将原始响应交回 `/mobile/<token>/upload` 由服务端解析入库。任务中的临时教务 Cookie 不写盘、不记日志；若手机端拉取失败则如实上报，由服务端兜底刷新。单元测试可通过 `./gradlew :app:testDebugUnitTest` 运行。
- **应用内检查更新**：启动 App 时每天最多自动检查一次 GitHub Releases，也可在“关于 → 检查更新”中手动触发。当无法直连 GitHub 时自动回退至本站镜像接口 `/android/releases.json`，安装包下载地址也同步切换为 `/android/apk/<版本>.apk`。发现新版本时主页展示更新卡片（可选择“先不更新”跳过当前版本），点击“立即更新”后由 App 下载安装包并在本地严格校验包名、版本号与签名证书，通过后拉起系统安装界面；首次更新需授予“安装未知应用”权限，若下载或校验失败可重试或改用浏览器下载。正式版仅检查正式版更新，预发布版同时检查正式版与预发布版。
- **权限状态管理**：首次启动引导弹窗后不会重复打扰，后续可随时在“我的 → 权限”中查看并跳转开启通知、准时提醒、系统实时提醒与后台运行权限；未允许后台不受限运行时，提醒卡片会给出提示与快捷设置入口。
- **跨平台实时通知说明**：**流体云仅适配 ColorOS 16+**；小米超级岛因需厂商企业开发者资质、应用商店上架及专项场景审核，当前未接入；其他系统（HyperOS、OriginOS、原生 Android 等）统一使用标准通知并在开课 5 分钟后自动清除。
- **图标致谢**：底部导航与方向图标采用 [IconPark](https://github.com/bytedance/IconPark)（Apache-2.0 许可证）单色矢量图标。

## 构建指南

环境要求：JDK 17+ 与 Android SDK（`compileSdk 37`）。可使用 Android Studio 直接打开 `android/` 目录，或在命令行构建：

```bash
cd android && ./gradlew :app:assembleDebug
```

构建产物位于 `app/build/outputs/apk/debug/app-debug.apk`。构建正式签名发布包时，请在 `android/keystore.properties`（已加入 `.gitignore`）中配置 `storeFile` / `storePassword` / `keyAlias` / `keyPassword`，然后执行 `./gradlew :app:assembleRelease`。

## 调试方法

- **连接本地离线演示站**：在项目根目录运行 `.venv/bin/python scripts/demo_server.py` 启动离线演示服务（端口 8765），登录后在设置页生成配对链接；模拟器或真机先执行 `adb reverse tcp:8765 tcp:8765`，即可直接使用包含 `localhost:8765` 的链接（`network_security_config` 已对 `localhost` 与 `10.0.2.2` 放行明文 HTTP）。
- **桌面小组件多尺寸预览（仅 Debug 包）**：无需反复往系统桌面拖拽，即可在一页内同时预览 2×2 至 4×5 以及窄列 2×3、3×3 等各种尺寸的排版效果；支持通过 `--es at 09:30` 指定模拟时刻以检查上课中、课前倒计时、课后切换明天等状态，或通过 `--es only 本周` 仅渲染指定类型的小组件：

  ```bash
  adb shell appwidget grantbind --package wiki.nufe.kebiao
  adb shell am start -S -n wiki.nufe.kebiao/.preview.WidgetPreviewActivity --es at 09:30
  ```

- **实时提醒测试（仅 Debug 包）**：进入“关于 → 开发者选项 → 实时提醒测试”可打开 Live Updates 调试页，直接验证流体云、普通通知回退及开课状态切换；点击“15 秒后闹钟测试”会通过真实的 `AlarmManager` 调度提醒，点击后按 Home 键退至后台即可验证准时唤醒。
- **Glance 布局约束注意**：Glance 的 `Row` / `Column` / `Box` 容器单个节点最多支持 10 个直接子元素，超出将导致小组件渲染报错；因此列间距统一采用 `padding` 而非独立 `Spacer`，单日课程每节仅占一个子元素。

## 代码结构

```text
app/src/main/java/wiki/nufe/kebiao/
  data/      Models（JSON 数据模型）、Repository（链接、缓存、配对与请求）、LocalFetch（手机端代抓）、
             AppUpdate（版本检查与下载校验）、Plan（今天 / 明天 / 本周展示计划，与 Scriptable 逻辑同源）
  widget/    Glance 桌面小组件：Common（主题配色、标题栏、倒计时、课程卡片）、DayWidget（今天，课后自动切明天）、
             WeekWidget（本周按节次）、WeekLayout（按内容自适应排版：节次/时间纵轴、文字测量、分档裁剪与对齐）
  sync/      WorkManager 后台同步、上下课边界重绘调度与登录失效通知
  remind/    本机上课提醒（AlarmManager + 标准通知 / ColorOS 流体云）与开机恢复
  diag/      运行日志环形缓冲与脱敏诊断文件导出
  ui/        Compose 界面：MainActivity、AppRoot、HomeScreen、MineScreen、AboutScreen、
             SetupScreen、ReminderSection、WidgetSection、UpdateFlow、GlassNav、CommonUi、Theme
app/src/debug/  小组件多尺寸预览页与实时提醒调试页
```

## 已知限制

- 国产定制系统（MIUI / HyperOS、ColorOS、OriginOS、HarmonyOS 等）默认会严格限制后台应用，请在系统电池或应用管理设置中允许本 App“自启动”与“后台不受限运行”，否则小组件刷新与课前提醒可能被系统推迟。
- 在会延后普通精确闹钟的系统上，课前提醒与“小组件准时切换”采用 `setAlarmClock` 调度，以避免被系统归入最长 1 小时的弹性合并窗口；代价是系统状态栏可能显示闹钟图标，锁屏界面也可能显示下一次闹钟时间。
- 若未授予“闹钟和提醒”（精确闹钟）权限（Android 12+ 需用户在系统设置中手动开启），课前提醒将降级为非精确闹钟，触发时间可能延后数分钟。
- 4×2 尺寸的“本周”小组件纵向空间较矮，仅能展示课程名称；4×3 及以上尺寸可完整显示教室并在左侧时间轴标注起止时间，4×4 及以上尺寸还可在卡片内同时展示起止时间、教学楼名与教师姓名。
